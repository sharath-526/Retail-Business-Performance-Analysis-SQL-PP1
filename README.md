# Retail Business Performance Analysis

**Practice Project 1 | MySQL**

## 1. Project Overview

This is my first SQL practice project, created as part of my Data Analyst learning journey.

The project focuses on analysing a fictional retail business using MySQL. I explored sales performance, product performance, customer behaviour and revenue trends.

The dataset is synthetic and AI-generated. It is used only for learning and SQL practice.

## 2. Business Objectives

- Understand overall sales performance.
- Identify monthly revenue trends.
- Analyse product and category performance.
- Understand customer purchasing behaviour.
- Explore customer segmentation.
- Practise advanced SQL concepts.

## 3. Dataset

The project uses six CSV files:

| File | Description |
|---|---|
| customers.csv | Customer information |
| products.csv | Product details |
| stores.csv | Store information |
| orders.csv | Order details |
| order_items.csv | Products within each order |
| payments.csv | Payment information |

**Dataset size:** 58,884 records across six tables.

**Period:** January 2024 – December 2025.

**Note:** All records are synthetic and do not represent real customers or transactions.

## 4. Tools Used

- MySQL
- DBeaver
- GitHub

## 5. Business Questions

### Sales Analysis
1. What is the overall sales performance?
2. How does monthly revenue change over time?
3. How do sales channels and order statuses compare?

### Product Analysis
4. Which products generate the highest revenue?
5. Which product categories contribute the most revenue?
6. How do discounts affect estimated profitability?

### Customer Analysis
7. Who are the highest-value customers?
8. How many customers make repeat purchases?
9. How can customers be segmented based on spending?

### Advanced Analysis
10. Which products rank highest within each category?
11. What is the cumulative monthly revenue?
12. What is the month-over-month revenue growth?

## 6. SQL Concepts Practised

- GROUP BY and HAVING
- Aggregate functions
- JOIN operations
- CASE statements
- Subqueries
- Common Table Expressions (CTEs)
- Window functions
- DENSE_RANK() and LAG()
- Running totals and revenue growth
